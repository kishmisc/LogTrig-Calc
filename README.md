# 🧮 Neumorphic Advanced Calculator (LogTrig-Calc)

A sleek, dark-themed Neumorphic calculator built with React and Vite. It goes beyond basic arithmetic by offering full support for custom-base logarithms, trigonometry, and symbolic calculus (differentiation and integration).

![Vite](https://img.shields.io/badge/Vite-5.0-purple)

**Live Demo:** [View the Calculator Here](https://kishmisc.github.io/LogTrig-Calc)

## ✨ Features

* **Premium UI:** Deep-night Neumorphic design with glowing cyan digital text and tactile button-press shadows.
* **Advanced Mathematics:** Powered by `mathjs` to handle complex string evaluations.
* **Calculus Engine:** * Symbolic Differentiation (`d/dx`)
  * Symbolic Integration (`∫dx`)
* **Custom Logarithms:** Calculate logs with any valid base using the dedicated Base Input field.
* **Trigonometry:** Instant `sin`, `cos`, and `tan` evaluations.
* **History Tape:** Automatically tracks and stores your most recent calculations in a scrolling digital ledger.

## 🛠️ Tech Stack

* **Frontend Framework:** React (Functional Components, Hooks)
* **Build Tool:** Vite
* **Math Engine:** Math.js
* **Styling:** Vanilla CSS3 (Custom variables, flexbox, grid, box-shadow depth)
* **Deployment:** GitHub Pages
